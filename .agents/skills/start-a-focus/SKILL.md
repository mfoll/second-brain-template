# Start a Focus

Start something new in the Brain through a short interview: an ongoing area, a finite outcome, a subject to explore or a first item to keep. A focus is the user's word, not a Type; the interview decides the Type.

For a single external item under existing work, use `ingest-source` directly.

## Source of truth

- Vault rules: `AGENTS.md`
- Type contracts: `responsibility.md`, `project.md`, `topic.md`
- Complete workflow: `procedures/start-a-focus.md`

Read the vault rules and Procedure completely, and the Type notes the proposal uses, before acting.

## Guardrails

- Ask one question at a time, at most about six; skip what the request already answers.
- Search and reuse existing notes before proposing new ones.
- Propose notes, Types and parents in plain language and wait for agreement before writing.
- Keep every `belongs_to` chain reaching a Responsibility; link existing material in place.
- Hand technical workspaces to Initialize Project Memory; create no folders, connections, schedules or global-instruction changes here.
- Verify retrieval from the entry note and report what was created, reused and left open.

Select this package by the requested vault role, not its name alone. Reuse rules and the complete Procedure already read in this session while they remain current; reread after a relevant change.
