# Ingest Source

Incorporate a paper, webpage, document or other external material into the vault, preserving provenance and connecting useful knowledge to existing notes.

For mixed or unclassified captures, use `process-inbox`, which delegates external material to this workflow.

Read the vault `AGENTS.md` and `procedures/ingest-source.md` once for this task, then follow the Procedure as the source of truth. Keep edits task-scoped and report changed files, validation, and follow-up. This package activates the workflow; it does not duplicate it.

Select this package by the requested vault role, not its name alone. Reuse rules and the complete Procedure already read in this session while they remain current; reread after a relevant change.
