# Process Inbox

Triage and organize unprocessed captures within the requested scope: internal ideas, questions, project updates and external material. Preserve useful details and leave blocked items unresolved.

For external material supplied directly, use `ingest-source`. To process only explicitly ready-marked captures, use `process-ready-ingestion-inbox`.

Read the vault `AGENTS.md` and `procedures/process-inbox.md` once for this task, then follow the Procedure as the source of truth. Keep edits task-scoped and report changed files, validation, and follow-up. This package activates the workflow; it does not duplicate it.

Select this package by the requested vault role, not its name alone. Reuse rules and the complete Procedure already read in this session while they remain current; reread after a relevant change.
