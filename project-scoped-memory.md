# Project Scoped Memory

Project-scoped memory lets an agent start from the logical vault role and Project note linked by a workspace pointer before searching the whole vault.

Add the memory section alongside the workspace's existing instructions. Keep canonical technical documentation and source files in their established locations; link to them rather than moving or duplicating them. The Brain stores selected context, decisions, questions and project state that help resume work. Durable non-versioned inputs, outputs and deliverables follow the deployment's chosen file strategy when one is needed.
