# Project Scoped Memory

Project-scoped memory lets an agent start from the logical vault role and Project note linked by a workspace pointer before searching the whole vault.

Project-scoped memory also means durable project knowledge should live in the vault, not in a parallel workspace `docs/` folder. Workspace files can hold scripts, prototypes, fixtures, generated outputs, and implementation-local notes, but design docs, workflow decisions, research notes, open questions, tool evaluations, and project state should become typed notes linked from the project or entry note.
