# Operation

An Operation is recurring work that can usually be completed in one sitting.

Use Operation notes for scheduled or repeated runs, review loops, checks, publishing routines, maintenance routines, or other recurring activities that should remain visible as part of a Responsibility or Project.

An Operation is not the same as a Procedure. The Operation records that the recurring activity exists, who or what it belongs to, its cadence, and its current operating state. A Procedure explains how to perform the activity.

Use the PORT action axes:

- `Responsibility`: recurring work larger than one sitting.
- `Project`: one-off work larger than one sitting.
- `Operation`: recurring work that can usually be completed in one sitting.
- `Task`: one-off work that can usually be completed in one sitting; do not create Task notes by default. Keep those in Project `## Next Actions` or a dedicated task manager unless the user explicitly chooses a task system.

Source model: [Portent Types](https://portent.md/types).
