# Guide

A Guide is a durable orientation, instruction, or compatibility document for humans, agents, tools, or project setup.

Use this Type for `README.md`, `AGENTS.md`, setup guides, and compatibility notes. Automatically loaded Guides stay compact and single-sourced; longer reference Guides should open with a short orientation and route detailed execution to Procedures.

When a Guide documents a third-party tool, repository, package, parser, or service, include its canonical source URL or another re-checkable provenance link.
